# Calculator solution

`calculator_solutions.sv` is the completed reference implementation. Try completing the starter in `rtl/calculator.sv` before checking it.

To simulate the solution, add this file **instead of** `rtl/calculator.sv` to your QuestaSim/ModelSim project. Keep the provided memory and testbench files. Do not compile both calculator files together: they define the same module.
